Schooling｜互動式 SQL 課程平台

讓想學 SQL 的人在瀏覽器裡直接練，不用裝資料庫、不用註冊、不用後端
完整的 SQL 學習路徑，每一課都附可執行的查詢環境，學習者在頁面裡直接寫 SQL、直接看到結果。 架構上刻意不做後端——以 WASM SQLite（sql.js）把資料庫跑在瀏覽器裡，因此零維運成本、使用者資料不離開瀏覽器； 自動批改採比對查詢結果而非 SQL 字串，同一題允許多種正確寫法，避免把「寫法不同」誤判成「答錯」。

03. 關於我

我專注於把 AI、資料與多平台串接 落地成能真正解決問題的系統。習慣從需求定義、資料模型、流程設計、實作到生產化維運一手包辦——例如自建 MCP server 讓 AI 直接、可靠地取用資料，同時兼顧成本、準確度與商業風險。

面對高風險流程時，我的做法是把驗證寫進系統：報價走保守防錯、AI 只有讀取與草稿權限、法規下架先比對再執行、自動批改比對結果而不是比對字串。錯誤不該靠人記得檢查。

學術背景是數學系（高雄大學）與經濟研究所（台北大學）。研究所期間擔任助教，負責出考題；大學時參與教育部偏鄉計畫擔任帶班老師。這段經歷讓我習慣先把「什麼叫做做到了」定義清楚，再開始動手。
