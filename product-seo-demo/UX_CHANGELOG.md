# 電商上架 SEO/GEO Demo — UX 變更紀錄

本檔記錄展示頁的 UX 決策、驗證方式與回退線索。每次修改前先保留 Git commit；若需回退，使用 `git revert <commit>`，避免覆蓋其他作品集頁面的變更。

## 2026-11-09 — 說明性流程改橫排精簡

### 目標

- 「上架與下架流程總覽」只是過程說明，不是這頁的展示重點，不該用整段垂直版面。
- 「安全發布」的說明同樣佔太多頁面高度，壓縮到一排即可。
- 版面高度讓給真正的互動區（AI 文案生成、頁面預覽、改版前後對比）。

### 變更

**1. 上架與下架流程總覽**

- 由垂直 6 格（寬 520px、向下箭頭）改為**橫排一排**，卡片高度 **約 480px → 82px**。
- 移除「▶ 重播流程」按鈕與「頁面載入會自動播一次；亦可手動重播」說明文字；載入時仍會自動依序亮燈一次。
- 標題去掉「（載入時依序亮燈）」括號說明。
- 對應 `script.js`：`playFlow()` 原本以 `runBtn.disabled` 當重入鎖，按鈕移除後會存取 null 而出錯；改用獨立的 `flowBusy` 旗標，並移除 `runBtn` 取得與 click 綁定。

**2. 安全發布 Pipeline**

- 原本「說明段落 ＋ 6 顆區塊庫 pill ＋ 垂直 5 格流程」三層堆疊。改為**一段說明（區塊庫名稱併入行內）＋ 橫排 5 格流程**，高度 **約 400px → 44px**。
- **保留「▶ 模擬安全發布」按鈕**：它會驅動下方③改版前後對比與④發布結果預覽，不是裝飾性按鈕，不可移除。

**3. 共用樣式**

- 新增 `.pipe-row` 修飾類：橫排、節點等寬（`flex:1 1 0`）、箭頭改為指向右方。
- ≤900px 改為每排 3 格；≤640px 單欄堆疊並隱藏箭頭（換行後水平箭頭會指向空白處）。
- 移除因此失效的 `.pill-row` / `.pill` 樣式。

### 驗證清單

- 1440px：兩個流程皆為**單排**（`rows1=1`、`rows2=1`），高度 82px / 44px；`runBtn` 不存在、`runBtn2` 仍存在。
- 1440px：點「模擬安全發布」後 5 個節點依序轉為 done、`pgPatchEmpty` 佔位被實際內容取代、按鈕正確解除停用。
- 390px：body 寬度 390、無水平溢位；流程堆疊為 6 排、箭頭 `content:none`。
- console 無錯誤；`node --check product-seo-demo/script.js` 與 `git diff --check` 通過。
